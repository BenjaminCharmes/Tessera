# Code de conduite

## L'essentiel

Soyez correct. Les désaccords techniques sont bienvenus — c'est le métier ;
les attaques personnelles ne le sont pas.

Concrètement, ce qui n'a pas sa place ici : les insultes, le harcèlement sous
toutes ses formes, les remarques sur ce que quelqu'un est plutôt que sur ce
qu'il écrit, la publication d'informations privées sans accord, et le mépris
affiché envers ceux qui débutent.

Ce qui aide : critiquer le code et non son auteur, accepter qu'on puisse
avoir tort, dire *pourquoi* on n'est pas d'accord, et supposer la bonne foi
avant de supposer la bêtise.

## Portée

Ce code s'applique partout où ce projet est en jeu : issues, pull requests,
discussions, commits.

## Signaler

Écrivez au mainteneur en privé, via son profil GitHub. Les signalements sont
traités confidentiellement, et je m'engage à ne pas retourner un signalement
contre la personne qui le fait.

Les réponses vont du simple mot au blocage définitif, selon la gravité et la
répétition. Sur un projet de cette taille, l'arbitre est unique — j'essaierai
d'être juste, et de m'expliquer plutôt que de trancher en silence.
